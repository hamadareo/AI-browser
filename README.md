# AI Browser

手元の PC で動くローカル AI（LM Studio など）を使って、ブラウザを自動で操作するエージェントです。
「Wikipedia で人工知能について検索して」のように日本語で頼むと、AI がページを読んで、クリックや入力、スクロールを自分で進めます。

クラウドの AI サービスを使わないので、API キーは要りません。

## 特徴

- **ローカル LLM で動く**: LM Studio など、OpenAI 互換の API を持つローカルサーバー（`http://localhost:1234/v1`）を使います
- **操作の様子が見える**
  - 操作できる要素に赤い番号ラベルを付けて、AI はその番号で操作を選びます
  - 青い仮想カーソルが、クリックする場所へ動きます
  - AI の考えていることと自己評価を、画面の左下に表示します
- **失敗から学ぶ（長期記憶）**: 操作の中で得た教訓を `memory.txt` に保存して、次に実行するときに読み込みます。似た教訓は重複しないように除きます
- **ループ対策**: 直前の操作の履歴とエラーを AI に渡して、同じ失敗を繰り返さないようにしています

できる操作: ページを開く、クリック、文字入力、Enter、上下スクロール、戻る、完了

## 2 つの使い方

| | Python 版（`main.py`） | Chrome 拡張版（`extension/`） |
| --- | --- | --- |
| ブラウザ | Playwright が新しく開く Chromium | いつも使っている Chrome |
| 指示の出し方 | ターミナルに入力 | サイドパネルのチャット欄に入力 |
| 長期記憶 | あり | なし |

## 準備するもの

1. **Python 3.12 以上**（Python 版を使う場合）
   - [Python 公式サイト](https://www.python.org/downloads/) からインストールしてください
   - Mac に最初から入っている Python（3.9）では動きません
   - **Windows の場合**: インストールするときに **「Add Python to PATH」** に必ずチェックを入れてください
2. **LM Studio（LLM サーバー）**
   - LM Studio でモデルを読み込み、Local Server をオンにしてください（ポート 1234）
   - 指示どおりの JSON をきちんと返せるモデルほど、うまく動きます

## Python 版の起動方法

難しいコマンド操作は要りません。使っている OS に合わせたファイルを**ダブルクリック**するだけで、環境の準備と起動が自動で行われます。

### Windows の場合
1. フォルダの中の `run_windows.bat` をダブルクリックします
2. 初めて起動するときは、必要なパッケージのインストールなどが自動で行われます。黒い画面（コマンドプロンプト）が開くので、終わるまでしばらく待ってください
3. 準備ができると、AI に頼みたいことを入力できるようになります

### Mac の場合
1. フォルダの中の `run_mac.command` をダブルクリックします
2. ターミナルが開き、初めてのときは準備が自動で行われます
3. 準備ができると、AI に頼みたいことを入力できるようになります

> **Mac で「開発元を検証できないため開けません」と表示された場合**
> ファイルを右クリック（または Control キーを押しながらクリック）して「開く」を選び、もう一度「開く」をクリックしてください。

起動すると DuckDuckGo が開き、そこから操作を始めます。最大 30 ステップで終わります。

## Chrome 拡張版の使い方

1. Chrome で `chrome://extensions` を開き、右上の「デベロッパー モード」をオンにします
2. 「パッケージ化されていない拡張機能を読み込む」を押して、`extension` フォルダを選びます
3. ツールバーの拡張機能アイコンを押すと、サイドパネルが開きます
4. LM Studio を起動した状態で、チャット欄に頼みたいことを入力します

## 注意事項

- AI はページに書かれた内容を読んで動くので、**悪意のあるページに書かれた指示に従ってしまう可能性があります**（プロンプトインジェクション）。ネットバンキングなど、大事なアカウントにログインしているページでは使わないでください
- Chrome 拡張版は、すべてのサイトでページの内容を読み取る権限を持ちます。使わないときは、拡張機能をオフにしておくと安心です
- AI が間違った操作をすることがあります。購入や送信など、取り消せない操作が起きそうなページでは使わないでください

## トラブルシューティング

- **「Python が見つかりません」というエラーが出る**
  Python がインストールされていないか、PATH（環境変数）が設定されていません。一度 Python をアンインストールして、もう一度インストールするときに「Add to PATH」にチェックを入れてください。

- **起動すると `SyntaxError` が出る**
  Python のバージョンが古いです。Python 3.12 以上をインストールしてください。

- **「ブラウザのインストールに失敗しました」というエラーが出る**
  ネットワークの接続を確認して、もう一度起動用のファイルをダブルクリックしてください。

- **「LLM Error」や「LM Studio への接続に失敗しました」と出る**
  LM Studio が起動していて、Local Server がポート 1234 でオンになっているか確認してください。
